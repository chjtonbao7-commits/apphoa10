# AGENTS.md

Guide for AI agents and developers working on this codebase.

## Project overview

**Thầy Schrödinger** is a Vietnamese-language learning companion for Hóa học 10 – Bài 3 "Cấu trúc lớp vỏ electron nguyên tử". Students log in with full name + class, then learn with an AI tutor role-playing Erwin Schrödinger, practise orbital diagrams, take a 10-question challenge and submit digital-competence evidence (NLS 5.3.NC1a). Teachers see per-class statistics with charts and personalised analysis per student.

All UI copy is Vietnamese. Keep it that way; the tutor addresses students as "em" and calls itself "Thầy Schrödinger".

    learning.server.ts     # server-only DB helpers (summarise, touch) — never import from client code
  components/          # Chat, OrbitalLab, Quiz, Tasks, MyResults, AnalysisCard, charts (HBarChart, ColumnChart, LevelBadge), OrbitalCloud (decorative SVG)

## Conventions & decisions

- **Socratic tutor.** The system prompt in `api.chat.ts` forbids giving answers directly, requires 2–4 sentence replies ending with one guiding question, and nudges students towards PhET / Orbital Viewer / ChemDoodle and Canva / PowerPoint. Hints in the lab and quiz follow the same rule: they point at the principle, never reveal the answer.
- **Grading happens on the server** using the same functions the client uses (`checkDiagram`, `gradeQuiz` in `chemistry.ts`), so stored results are trustworthy and content lives in one place. To add questions or elements, edit `chemistry.ts` only.
- **Orbital cells** cycle `'' → u → ud → d → uu`. `uu` (↑↑) exists deliberately so Pauli mistakes can be made and detected. Single electrons must point up (↑) per the textbook convention for Hund's rule.
- **Identity is lightweight**: a student is unique by (name, class), upserted on login; class names are uppercased. No passwords — this is a classroom tool. The teacher statistics page is currently public.
- **Mastery index** (0–100) = 50% best challenge score + 20% orbital lab (3 correct elements = full) + 30% NLS tasks. Levels: ≥80 Tốt, ≥60 Khá, ≥40 Đạt, else Cần hỗ trợ. Defined in `analysis.ts`.
- **Charts** are hand-built HTML/CSS (no chart library), single-series, with hover tooltips. Blue `#2a78d6` is the default series colour, orange `#eb6834` for rule-violation counts; level colours are status colours always paired with an icon + label.
- Schema changes: edit `db/schema.ts`, then `npx drizzle-kit generate --name <verb_description>`. Never apply migrations manually; Netlify applies them on deploy.
- Do not run build/dev commands in agent sessions; the platform builds and validates.
